# Security Policy

## Scope

This project contains documentation and AI skill/prompt files — no executable code with user data, authentication, or network access. The attack surface is minimal.

## Reporting a Vulnerability

If you find a security issue — for example, prompt injection guidance that could cause harm, or a checklist item that gives dangerously wrong security advice — please do not file a public GitHub issue.

Instead:
1. Use [GitHub's private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) for this repository, or
2. Open a GitHub issue titled `[SECURITY] <brief description>` if private reporting is unavailable.

We will acknowledge reports within 5 business days and aim to resolve confirmed issues within 30 days.

## Out of Scope

- Vulnerabilities in Cursor, GitHub, or other tools this skill integrates with
- General AI hallucination behavior (this is documented as a limitation, not a security vulnerability)
