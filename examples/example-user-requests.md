# Example User Requests

15 realistic requests a developer might give to Cursor with this skill installed.

---

1. "Review this repo before I contribute: https://github.com/expressjs/express"

2. "I found a bug in a popular npm package and want to submit a fix. What do I need to check first?"

3. "What license does this project use? I want to make sure I can contribute code I wrote at my day job."

4. "Does this project need me to sign a CLA? I've heard some projects require that."

5. "I've never contributed to open source before. Walk me through what to check before opening my first PR."

6. "Summarize what the CONTRIBUTING.md says for this project." [paste CONTRIBUTING.md]

7. "What's the security disclosure process for this repo? I might have found a vulnerability."

8. "I want to contribute to a GPL project. My employer owns my code. What do I need to figure out?"

9. "Check if this project has a code of conduct and summarize what it says."

10. "I'm about to open a PR. Give me a pre-flight checklist based on this project's CONTRIBUTING.md." [paste CONTRIBUTING.md]

11. "This project has no README, no license, no CONTRIBUTING.md — just source code. Is it safe to fork and modify?"

12. "What commit message format does this project use? I see some commits but no docs about it."

13. "The maintainer asked me to add DCO sign-off. What is that and how do I do it?"

14. "I want to open an issue to report a bug. What should I include based on this project's issue templates?" [paste issue template]

15. "I've been contributing to this project for 6 months. The maintainer changed the license from MIT to AGPL. What does that mean for my previous contributions?"
