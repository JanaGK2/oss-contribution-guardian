# Contributing to OSS Contribution Guardian

Thanks for considering a contribution. This project is deliberately small and focused — please keep that in mind when proposing changes.

## What's Welcome

- Corrections to factually wrong guidance
- New or improved checklist items with a clear rationale
- Additional worked examples in `examples/`
- Improvements to clarity or tone (concise, not preachy)
- Support for additional Cursor / AI assistant integration patterns
- Translations of the skill docs (open an issue first)

## What's Not a Good Fit

- Adding employer-specific or proprietary policy rules to the core skill
- Making the skill more prescriptive than the referenced OSS guides support
- Rewriting the skill to give legal advice

## Process

1. **Open an issue first** for anything beyond a typo fix — describe what you want to change and why.
2. Fork the repo and create a branch: `git checkout -b fix/my-change`
3. Make your change. Keep it focused — one concern per PR.
4. Update `CHANGELOG.md` with a brief entry under `[Unreleased]`.
5. Open a PR with a clear description referencing the issue.

## Code of Conduct

See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). We follow the Contributor Covenant.

## Sign-off

No CLA required. By submitting a PR, you agree that your contribution is made under the MIT License.

If your employer owns your code contributions (common in some jurisdictions), you are responsible for ensuring you have permission to contribute.
